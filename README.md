# Lab3

## Compilar

Desde la raíz del proyecto, compila las clases Java y genera los archivos `.class` en la carpeta `bin`:

```bash
javac -d bin src/*.java
```

## Ejecutar

Una vez compilado, ejecuta la clase principal:

```bash
java -cp bin Main
```

Esto inicia la aplicación de gestión de envíos desde la consola.
